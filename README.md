# Kipinä-pilot

Digitaalisen osallisuuden alusta nuorille. Ideasta ensimmäiseksi askeleeksi.

Kipinä-pilot auttaa nuoria sanoittamaan ideansa ja vie sen kohti toimivaa digitaalista ratkaisua.

## Rakenne

- `apps/frontend/` — käyttäjälle näkyvä React-sovellus
- `apps/reveal-data-api/` — backend-integraatio Reveal Engineen
- `infra/` — Caddy ja infrastruktuurikonfiguraatiot
